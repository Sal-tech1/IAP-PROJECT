# ICS 2203: Internet Application Programming Capstone Project
**Project Title:** A Simple Responsive Web Application with Database Integration

## Project Overview
This is a responsive web application built using PHP, MySQL, HTML/CSS, and JavaScript. The project demonstrates core skills in form handling, CRUD operations, and session management.

## Technologies Used
* **Backend:** PHP (PDO), MySQL
* **Frontend:** Bootstrap, CSS Flexbox/Grid, JavaScript
* **Tools:** Git, GitHub, XAMPP

## How to Run Locally
1. Clone the repository: `git clone https://github.com/Sal-tech1/IAP-PROJECT.git`
2. Import `schema.sql` into your local MySQL database.
3. Configure `config.php` with your local DB credentials.
